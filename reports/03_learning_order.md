# 03. 50개 데이터셋 추천 학습 순서

> 50개를 1번부터 순서대로 공부하지 말고, 아래 9단계를 따라가는 것을 추천합니다.
> 각 단계는 [`02_manufacturing_domain_overview.md`](02_manufacturing_domain_overview.md)의 특정 절과 연결되어 있으니, 막히면 그 절을 다시 읽으세요.
> 전체 흐름: **①기본 가공공정 → ②품질과 불량 → ③공정조건(연속공정) → ④설비와 센서 → ⑤설비 이상탐지·예지보전 → ⑥이미지 검사 → ⑦오디오 검사 → ⑧공정 최적화 → ⑨자원/공급망/생산계획 최적화**

각 데이터셋 항목은 다음을 담고 있습니다: **왜 지금 공부하는지 / 데이터 한 행·target·데이터형태 / 같이 볼 용어 / 다음과의 연결**

> 참고: 이 순서는 임의로 정한 게 아니라 [`01_kamp_50_domain_map.md`](01_kamp_50_domain_map.md)에서 각 데이터셋의 구조·라벨 방식·문제정의를 49개와 비교해 매긴 우선순위(A/B/C)의 결과입니다. "여기 먼저 나온다=중요하다"가 아니라 "중요하다고 판단됨(A)→그래서 먼저 배치함"이라는 순서입니다.

## 1단계 — 기본 가공공정 감 잡기 (시계열 벤치마크 + 절삭·성형·용접 기초)

### 2. Ford 엔진 진동  `[A급]`
- **왜 지금**: 50개 중 유일하게 이미 완벽히 정제된 공개 벤치마크. '시계열 파형 한 덩어리 = 관측치 하나'라는, 이후 진동/전류 데이터(30번 등)에서 계속 나오는 데이터 형태를 가장 쉬운 형태로 먼저 연습할 수 있음
- **데이터 형태**: 시계열 텍스트(ARFF/txt), 500개 포인트짜리 파형 1개=1행
- **한 행의 의미**: 한 번의 측정 파형(500개 시점의 값이 한 행에 나열됨)
- **target(정답)**: 정상/비정상(이진 라벨, 이미 부여되어 있음)
- **분석 유형**: 시계열 분석, 불량 탐지
- **같이 볼 용어**: 시계열 분류 _(자세한 뜻은 02 문서 8장 glossary 참고)_
- **다음과의 연결**: 이 '파형=1행' 형태를 실제 제조 진동 데이터인 13번(회전기계)에서 다시 만나게 됨

### 3. CNC 머신  `[A급]`
- **왜 지금**: 설정값(Set)과 실제값(Actual)을 나란히 기록하는 제조데이터의 가장 전형적인 구조를 보여주는 첫 사례. 조건표(train.csv)와 시계열(experiment.csv)이 분리되어 있어 '조건 데이터'와 '센서 데이터'를 연결하는 감각을 기를 수 있음
- **데이터 형태**: 정형 시계열(experiment_XX.csv, 48개 센서 컬럼) + 실험조건/라벨(train.csv)
- **한 행의 의미**: experiment_XX.csv: 한 실험(가공 1회) 동안의 시점별 축(X/Y/Z) 위치·속도·전류 등. train.csv: 실험 1회=1행(조건+결과)
- **target(정답)**: tool_condition(worn/unworn), passed_visual_inspection(Y/N) — train.csv에 explicit 라벨
- **분석 유형**: 품질 분류, 설비 이상탐지
- **같이 볼 용어**: MCT, spindle, feed rate, 공구 마모 _(자세한 뜻은 02 문서 8장 glossary 참고)_
- **다음과의 연결**: 같은 '조건→불량' 구조를 성형공정에 적용한 4번(Molding)으로 이어짐

### 4. 사출성형기  `[A급]`
- **왜 지금**: '왜 불량인지'까지 텍스트로 라벨링된 드문 사례. 라벨 있는/없는 데이터가 같이 있어 준지도학습(현업에서 라벨링 안 된 데이터가 더 많은 현실)을 처음 접하기 좋음
- **데이터 형태**: 정형 Lot 단위 데이터(csv), labeled+unlabeled 혼재
- **한 행의 의미**: 한 행 = 사출 1회(Lot) — Injection_Time, Filling_Time 등 그 회차의 공정조건 요약값
- **target(정답)**: PassOrFail(Y/N) + Reason(불량 사유 텍스트)
- **분석 유형**: 품질 분류
- **같이 볼 용어**: 사출성형, cycle time, 클램핑 _(자세한 뜻은 02 문서 8장 glossary 참고)_
- **다음과의 연결**: 같은 '판을 눌러 성형'하는 프레스(7번)로 대비해보면 사출과 프레스의 차이가 뚜렷해짐

### 5. 용접기(스팟용접)  `[A급]`
- **왜 지금**: '불량 라벨이 없을 때 어떻게 문제를 푸는가'를 보여주는 첫 사례(비지도 이상치 탐지). 5장(품질과 불량)의 불균형 데이터 문제를 가장 단순한 형태로 체감할 수 있음
- **데이터 형태**: 정형 시계열(csv, 정규화됨)
- **한 행의 의미**: 한 행 = 용접 1타(spot 1회)의 소재두께/가압력/전류/전압/통전시간
- **target(정답)**: 명시적 라벨 없음 — 오토인코더로 '정상 분포에서 벗어난 샘플'을 이상치로 판정
- **분석 유형**: 불량 탐지
- **같이 볼 용어**: 스팟용접, 통전시간, 오토인코더 _(자세한 뜻은 02 문서 8장 glossary 참고)_
- **다음과의 연결**: 같은 '불량 라벨 없이 이상치로 접근' 방식을 설비 진동에 적용하면 5단계(예지보전)의 여러 데이터셋과 이어짐

### 7. 프레스기(벤딩)  `[B급]`
- **왜 지금**: 지도학습(정답 있음) 없이도 '몇 종류의 패턴이 섞여 있는지' 자체를 알아내는 군집화(비지도학습)의 예시. 3~5번(CNC/Molding/Welding)과 대비해 같은 성형/접합 계열이라도 접근법이 다양함을 확인
- **데이터 형태**: 정형 시계열(csv, 정규화됨)
- **한 행의 의미**: 한 행 = 프레스 1회 동작의 속도/압력값
- **target(정답)**: 명시적 라벨 없음 — GMM으로 정상+비정상 3종=4개 군집 자동 분류
- **분석 유형**: 불량 탐지, 공정 분석
- **같이 볼 용어**: 소성가공, 군집화 _(자세한 뜻은 02 문서 8장 glossary 참고)_
- **다음과의 연결**: 다음 단계(2장, 품질/불량)에서는 라벨이 명확한 배치형 품질 데이터(37 등)로 넘어감


## 2단계 — 품질과 불량 (Lot/Shot 단위 정형 품질검사)

### 37. 주조 품질보증(다이캐스팅)  `[A급]`
- **왜 지금**: 컬럼 헤더 자체가 'Process→Sensor→Defects' 순서로 그룹화되어 있어, 1장에서 배운 '공정조건→현상→불량'의 파이프라인을 데이터 구조에서 그대로 확인할 수 있는 가장 좋은 교과서적 예시
- **데이터 형태**: 정형 Shot 단위 데이터(csv, 컬럼이 Process/Sensor/Defects로 그룹화됨)
- **한 행의 의미**: 한 행 = shot(사출) 1회 — Velocity/Pressure 등 공정조건(Process) + 센서값(Sensor) + 여러 불량유형(Defects, 0/1) 동시 기록
- **target(정답)**: Defects 그룹의 여러 불량유형 컬럼(다중 라벨 가능)
- **분석 유형**: 품질 분류
- **같이 볼 용어**: 다이캐스팅, shot, biscuit thickness _(자세한 뜻은 02 문서 8장 glossary 참고)_
- **다음과의 연결**: 같은 설비를 '예지보전' 관점(49번)으로 다시 보러 이동

### 26. 화장품 품질보증  `[B급]`
- **왜 지금**: 공정 센서 로그(수만~수십만 행)와 품질검사표(단 22행)의 '측정 빈도 차이'를 처음 명확히 보여주는 사례 — 실무에서 이 둘을 어떻게 이어붙일지 고민하게 됨
- **데이터 형태**: 정형 시계열(Process_Data) + 소량 품질검사표(QC_Data)
- **한 행의 의미**: Process_Data: 한 행=한 시점의 반응조 A~F 온도/전류. QC_Data: 한 행=하루치 품질검사 결과(중량/수분 등)
- **target(정답)**: QC_Data의 품질 측정값(연속값)
- **분석 유형**: 품질 예측
- **같이 볼 용어**: Lot(비교개념) _(자세한 뜻은 02 문서 8장 glossary 참고)_
- **다음과의 연결**: 같은 '소량의 정밀 품질검사표' 구조를 가진 의류(43번)로 이동

### 33. 소성가공 품질보증(압출)  `[B급]`
- **왜 지금**: 사출성형(4번)과 원리는 비슷하지만(재료를 밀어냄) '압출'이라는 연속 성형 공정의 존별(zone) 온도 관리 패턴을 보여주는 사례 — 열처리(29번)의 zone 개념과도 연결됨
- **데이터 형태**: 정형 시계열(csv, 존별 온도)
- **한 행의 의미**: 한 행 = 한 시점의 EX1~5 zone별 온도/압력 측정값
- **target(정답)**: passorfail(0/1)
- **분석 유형**: 품질 분류
- **같이 볼 용어**: 소성가공, Zone _(자세한 뜻은 02 문서 8장 glossary 참고)_
- **다음과의 연결**: 같은 Lot 단위 품질판정 구조를 가진 42번(기계부품)으로 이동

### 34. 정밀가공 품질보증  `[B급]`
- **왜 지금**: 3번(CNC)의 '시점별 원본 시계열'과 달리, 이미 max/mean 같은 통계값으로 요약(feature engineering)된 형태 — 원본 시계열을 어떻게 표 형태로 바꾸는지 감을 잡을 수 있음
- **데이터 형태**: 정형 Lot 단위 데이터(csv, 통계 파생변수)
- **한 행의 의미**: 한 행 = 가공 1건(SerialNo)의 스핀들속도/서보전류/서보부하의 max/mean 등 통계 요약값
- **target(정답)**: explicit 라벨 컬럼 없음 — 공식 설명상 별도 판정결과와 결합해 분류(추론)
- **분석 유형**: 품질 분류
- **같이 볼 용어**: spindle, feed rate(비교개념) _(자세한 뜻은 02 문서 8장 glossary 참고)_
- **다음과의 연결**: 비슷한 통계요약형 품질데이터인 33/42번과 비교하며 정리

### 42. 기계부품 품질보증(냉간단조)  `[B급]`
- **왜 지금**: 실제 컬럼 이름 상당수가 결측(빈 값)으로 채워져 있어, '현실의 제조데이터는 깨끗하지 않다'(결측치 처리가 필요하다)는 걸 눈으로 확인할 수 있는 좋은 사례
- **데이터 형태**: 정형 시계열(csv, 초 단위, 결측 많음)
- **한 행의 의미**: 한 행 = 한 시점의 여러 모터별 전류/주파수/상태값(설비 하나에 측정점이 매우 많음)
- **target(정답)**: explicit 라벨 컬럼은 별도 결합 필요(공식설명상 XGBoost Classifier로 품질 분류, 정확한 target 컬럼명은 추가 확인 필요 — 추론)
- **분석 유형**: 품질 분류, 설비 이상탐지
- **같이 볼 용어**: 냉간단조, 결측치 _(자세한 뜻은 02 문서 8장 glossary 참고)_
- **다음과의 연결**: Lot/배치형 품질데이터 학습을 마무리하고 이미지·오디오군(6~7단계)로 이동, 또는 곧바로 43번 의류로

### 43. 의류 품질보증(염색)  `[B급]`
- **왜 지금**: '색상'이라는, 지금까지와는 전혀 다른 종류의 품질 기준(색차)을 다루는 사례. 사람 눈(육안)과 기계측정(CCM)의 판정이 다를 수 있다는 현장 이슈가 공식 설명에 명시되어 있어, '측정 자체의 신뢰도' 문제를 처음 접할 수 있음
- **데이터 형태**: 정형 시계열(csv/xlsx, 원본은 27번과 동일 소스)
- **한 행의 의미**: 한 행 = LOT 1건의 작업조건(목표온도/진행온도/포속 등) + 염색색차 DE(색상 오차)
- **target(정답)**: 염색색차 DE(연속값, 작을수록 목표 색상에 가까움)
- **분석 유형**: 품질 예측
- **같이 볼 용어**: Lot, CCM(컬러 측정기) _(자세한 뜻은 02 문서 8장 glossary 참고)_
- **다음과의 연결**: 같은 원본 데이터를 '공정최적화' 관점으로 다시 본 46번과 바로 비교

### 44. 열처리 품질보증  `[B급]`
- **왜 지금**: 29번(예지보전 관점)과 원본이 같은 설비 데이터를 '품질' 관점으로 다시 본 사례 — 2장(품질과 불량)의 마지막 정리 지점
- **데이터 형태**: 정형 시계열(csv, 29번과 거의 동일 컬럼) + 소량 품질표(xlsx)
- **한 행의 의미**: 29번과 동일(존별 온도 시계열) + 별도의 소량 품질판정표(136건)
- **target(정답)**: 품질표의 양/불 판정
- **분석 유형**: 품질 분류
- **같이 볼 용어**: Zone, 염욕 _(자세한 뜻은 02 문서 8장 glossary 참고)_
- **다음과의 연결**: 같은 원본의 '최적화' 버전인 45번으로 이동


## 3단계 — 공정조건과 연속공정 모니터링

### 8. 용해탱크  `[A급]`
- **왜 지금**: '불량이 난 뒤 원인분석'이 아니라 '불량이 나기 전에 미리 안다'는 예지적 품질분석 개념을 LSTM 시계열 모델로 처음 접하는 자리. 3장(연속공정군)의 표준 사례
- **데이터 형태**: 정형 시계열(csv, 시간 간격 규칙적)
- **한 행의 의미**: 한 행 = 한 시점의 용해온도/교반속도/중량 측정값
- **target(정답)**: INSP(OK/그 외 — 품질 판정 결과)
- **분석 유형**: 품질 예측, 시계열 분석
- **같이 볼 용어**: SOP, 저온살균(비교개념) _(자세한 뜻은 02 문서 8장 glossary 참고)_

## 9단계 — 자원·공급망·생산계획 최적화 (제조현장을 넘어선 운영 관점)

### 18. 자원 최적화  `[B급]`
- **왜 지금**: '설비 하나'가 아니라 '공장 전체'가 분석 단위가 되는 첫 사례. 제조 현상 자체보다 자원(에너지) 관리 관점이라는 걸 명확히 구분
- **데이터 형태**: 정형 시계열(csv, 15분 단위)
- **한 행의 의미**: 한 행 = 15분 단위 시간대의 생산량/기온/습도/전력 사용량
- **target(정답)**: 전력 사용량(연속값)
- **분석 유형**: 공정 최적화, 기타
- **같이 볼 용어**: 기타(전력수요예측) _(자세한 뜻은 02 문서 8장 glossary 참고)_
- **다음과의 연결**: 같은 자원최적화 문제를 특정 라인(표면처리·소성가공)에 적용한 25/31번과 비교

### 17. 공급망 최적화  `[C급]`
- **왜 지금**: 지금까지 본 '공정 안에서 벌어지는 현상'이 아니라, 그 공정에 '무엇을 얼마나 넣을지' 결정하는 경영/물류 문제로 관점이 바뀌는 첫 사례
- **데이터 형태**: 정형 테이블(xls, 시간대별 발주량)
- **한 행의 의미**: 한 행 = 부품(Part) 1개의 시간대별 발주계획 수량
- **target(정답)**: 미래 시점의 발주 수량(연속값)
- **분석 유형**: 시계열 분석, 기타
- **같이 볼 용어**: Lot(재고관리 맥락) _(자세한 뜻은 02 문서 8장 glossary 참고)_
- **다음과의 연결**: 비슷한 성격의 자원배분 문제(18번, 자원최적화)로 이동

### 20. 생산계획 최적화  `[C급]`
- **왜 지금**: 지금까지의 '데이터로 정답을 예측'하는 문제가 아니라 '제약 조건 안에서 최선의 배치를 찾는' 스케줄링(운영과학) 문제라는 걸 구분하는 사례
- **데이터 형태**: 정형 테이블(csv/xlsx, 설비용량+주문목록)
- **한 행의 의미**: machine_info: 설비 1대의 용량. order_info: 주문 1건의 납기/수량/단가
- **target(정답)**: 명시적 라벨 없음 — 유전알고리즘으로 설비×주문 배치의 '좋은 조합'을 탐색
- **분석 유형**: 기타
- **같이 볼 용어**: 기타(생산계획 스케줄링) _(자세한 뜻은 02 문서 8장 glossary 참고)_
- **다음과의 연결**: 9단계(자원/공급망 최적화)의 마지막 사례로, 여기까지 오면 8~9단계 전체가 '제조현상 예측'과는 다른 종류의 문제라는 게 정리됨

### 21. 표면처리 공급망최적화  `[C급]`
- **왜 지금**: 14~16번과 '같은 표면처리 라인'이라는 이름을 달고 있지만 내용은 완전히 물류 문제 — 이름만 보고 공정 데이터로 오해하지 않는 연습
- **데이터 형태**: 정형 테이블(csv, 생산+출고 이력)
- **한 행의 의미**: 한 행 = 작업지시 1건의 생산~다차 출고 이력
- **target(정답)**: 명시적 라벨 없음 — 유전알고리즘으로 재고 최소화 생산량 탐색
- **분석 유형**: 기타, 시계열 분석
- **같이 볼 용어**: Lot, 기타 _(자세한 뜻은 02 문서 8장 glossary 참고)_
- **다음과의 연결**: 같은 패턴의 22번(열처리 공급망최적화)과 비교

### 22. 열처리 공급망최적화  `[C급]`
- **왜 지금**: 21번과 같은 유형(공급망) 문제를 다른 업종(열처리)에 적용한 사례 — 업종은 달라도 문제 구조가 같다는 걸 확인
- **데이터 형태**: 정형 테이블(csv, 품목별 수급)
- **한 행의 의미**: 한 행 = 시간대별 품목 1개의 생산필요량/재고/생산량/수주량
- **target(정답)**: 미래 출고 수량(연속값)
- **분석 유형**: 시계열 분석, 기타
- **같이 볼 용어**: 기타 _(자세한 뜻은 02 문서 8장 glossary 참고)_
- **다음과의 연결**: 공급망 계열의 마지막 사례인 23번으로 이동

### 23. 사출성형 공급망최적화  `[C급]`
- **왜 지금**: 17/21/22번과 같은 '수요예측' 문제 유형의 반복 — 여기서는 온도·습도 같은 외부요인까지 변수로 들어간다는 차이
- **데이터 형태**: 정형 시계열 테이블(csv, 제품별 수주량)
- **한 행의 의미**: 한 행 = 제품 1종의 특정 시점 수주량 기록(예정/예상 수주량 포함)
- **target(정답)**: 향후 수주량(연속값)
- **분석 유형**: 시계열 분석, 기타
- **같이 볼 용어**: 기타 _(자세한 뜻은 02 문서 8장 glossary 참고)_
- **다음과의 연결**: 자원최적화 계열(25,31번)로 이동해 '수요예측'과 '자원배분'의 차이를 비교

### 25. 표면처리 자원최적화  `[C급]`
- **왜 지금**: 18번(전력)과 같은 '자원최적화' 유형이지만 대상이 '사람(인력)'이라는 차이 — 자원최적화가 에너지에만 국한되지 않는다는 걸 확인
- **데이터 형태**: 정형 시계열(csv, 15분 단위)
- **한 행의 의미**: 한 행 = 15분 단위 시간대의 생산량/기온/습도/투입인력/전력비용
- **target(정답)**: 필요 노동력(연속값) → 선형계획모델로 인원수 도출
- **분석 유형**: 공정 최적화, 기타
- **같이 볼 용어**: 기타 _(자세한 뜻은 02 문서 8장 glossary 참고)_
- **다음과의 연결**: 같은 유형을 소성가공 라인에 적용한 31번으로 이동

### 31. 소성가공 자원최적화  `[C급]`
- **왜 지금**: 18/25번과 같은 '자원(에너지)최적화' 유형을 소성가공 라인에 적용한 사례 — 이 지점까지 오면 자원최적화 계열이 업종만 바뀌며 반복된다는 패턴이 뚜렷해짐
- **데이터 형태**: 정형 시계열(xls, 설비별 전류)
- **한 행의 의미**: 한 행 = 한 시점의 설비 ID별 전류량/공정정보
- **target(정답)**: 전력 소모량(연속값)
- **분석 유형**: 공정 최적화
- **같이 볼 용어**: 소성가공, 기타 _(자세한 뜻은 02 문서 8장 glossary 참고)_
- **다음과의 연결**: 자원/공급망 최적화 계열 학습을 마치고 이미지·오디오 검사(6~7단계, 앞서 학습했다면 복습)로 정리

## 최종 점검 체크리스트

50개를 다 훑었다면, 처음 보는 제조 데이터셋을 만났을 때 아래 6가지에 스스로 답해보세요 (02 문서 9장과 동일):

1. 어느 업종/공정에 가까운가? (컬럼명의 전문용어를 단서로)
2. 어떤 설비가 관련되어 있는가?
3. 데이터 한 행은 무엇을 의미하는가? (시점 하나? 제품/Lot/Shot 하나?)
4. target(정답 라벨)이 있는가, 없는가?
5. 이 데이터는 품질 데이터인가, 설비 데이터인가, 공정조건 데이터인가?
6. 분석 문제 유형은 무엇에 가장 가까운가? (품질예측/품질분류/불량탐지/설비이상탐지/예지보전/공정분석/공정최적화/이미지검사/시계열분석/기타)

이 여섯 질문에 스스로 답할 수 있다면 목표를 달성한 것입니다.
