# KAMP EDA GUI

KAMP 제조 CSV를 업로드하면 데이터 구조를 파악하고, 사용자가 선택한 분석 목적과 변수에 따라 기초 기술통계·시각화를 보여주는 Streamlit 도구입니다.

전체 설계 명세(단일 진실 공급원, SSOT)는 [`docs/eda_gui_spec.md`](docs/eda_gui_spec.md)를 따릅니다.

## 프로젝트 목적

CSV를 업로드하고, 사용자가 원하는 분석 목적과 변수를 선택하면 기초 기술통계와 적절한 시각화를 제공합니다. 데이터 의미·분석 목적을 자동으로 추론하지 않고, 구조(행/열/dtype)는 프로그램이 보여주되 의미 있는 선택(라벨, 시간축, 그룹, 분석 변수)은 항상 사용자가 직접 합니다.

## 현재 상태

MVP 기능 구현 완료 (Phase 0~8).

## 기능

- CSV 업로드 — 인코딩 자동감지(UTF-8 → CP949 → EUC-KR) 실패 시 수동 선택, 헤더 행 지정, 헤더 없음 옵션, 원본 미리보기
- 데이터 개요 / 컬럼 프로파일(dtype·결측·unique) / 기술통계(수치형·범주형) — 전체 데이터 기준 계산
- 5개 분석 목적 (아래 참고), 분석 목적 전환 시 업로드·프로파일링 결과를 캐싱해 재사용

## 분석 목적

| 목적 | 내용 |
|---|---|
| 변수 분포 확인 | 수치형: 히스토그램·박스플롯·기술통계(count/mean/std/min/25%/median/75%/max/skew/missing) · 범주형: 막대그래프 |
| 변수 간 관계 확인 | 수치형 변수 다중 선택 → Pearson 상관관계 히트맵 + 산점도 |
| 그룹별 비교 | 사용자가 지정한 그룹 컬럼 기준 count/비율/mean/std + 박스플롯/히스토그램 (그룹 의미는 판단하지 않음) |
| 시간에 따른 변화 확인 | 시간순 정렬 라인차트, rolling mean 옵션, 결측 구간은 선 끊김으로 표시 (이상탐지 아님) |
| 통계적 이상치 탐색 | IQR(1.5×IQR) 기준 이상치 개수/비율 + 박스플롯, 시간축 지정 시 이상치 위치 표시 (모델 기반 이상탐지 아님) |

## 설치

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## 실행

```bash
streamlit run app.py
```

## 지원 CSV

CSV 정형 데이터만 지원합니다(이미지·오디오 제외).

## 테스트

```bash
pytest tests/
```

핵심 분석 로직(`src/`)은 pytest로 단위 테스트하며, 실제 KAMP CSV(`dataset/` 폴더, 저장소에는 미포함 — `.gitignore` 처리)로 인코딩 깨짐·2행 헤더·헤더 없음·대용량(80만 행 이상)·결측 많음 등 실제 엣지 케이스를 검증했습니다.
