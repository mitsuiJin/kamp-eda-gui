# KAMP 50개 제조 AI 데이터셋 개요

KAMP(인공지능 제조 플랫폼)에 등재된 무료 제조 AI 데이터셋 50개를 실제로 열어서(zip 내부 컬럼 구조, 공식 가이드북) 정리한 표입니다. 대회에서 어떤 데이터셋이 나오더라도 빠르게 "이게 어떤 유형인지" 감을 잡을 수 있도록, 아래 정보를 모든 데이터셋에 대해 통일된 기준으로 정리했습니다.

## 표를 읽는 법

| 컬럼 | 의미 |
|---|---|
| 산업/업종 | 어느 제조업종 데이터인지 |
| 제조공정 | 그 업종 안에서 구체적으로 어떤 공정 단계인지 |
| 주요 설비 | 데이터를 만들어낸 장비 |
| 데이터 형태 | 파일 종류, 한 행의 단위 |
| 해결하려는 제조 문제 | 이 데이터셋이 실제로 다루는 이슈 |
| 분석 유형 | 품질예측 / 품질분류 / 불량탐지 / 설비이상탐지 / 예지보전 / 공정분석 / 공정최적화 / 이미지검사 / 시계열분석 / 기타 |
| 핵심 제조 키워드 | 검색·복습용 키워드 |
| 우선순위 | 아래 참고 |

**우선순위(A/B/C)** — 데이터셋 구조·라벨 방식·문제정의가 50개 중 같은 패턴을 대표하는 정도로 매겼습니다.
- **A**: 특정 패턴(예: 라벨 없는 데이터 다루기, 이미지 객체탐지 등)을 가장 전형적으로 보여주는 데이터셋
- **B**: A와 같은 패턴을 다른 설비·공정에 적용했거나 이미 가공된 형태
- **C**: 새로 배울 패턴이 없거나(다른 데이터셋과 원본이 사실상 동일), 온도·진동 같은 제조 현상이 아니라 발주량·인력 배치 같은 경영/물류 데이터
