# 대회 전까지 추진 방향

## 목표

각자 **공정 / 품질 / 설비** 관점 중 하나를 골라, 그 관점에 해당하는 데이터셋을 하나 선택해서 **모의 데이터분석을 직접 해보고, 팀 내에서 발표 + 피드백**을 받습니다. 목적은 정답을 맞히는 게 아니라, `3_데이터분석_프로세스`를 실제로 한 번 완주해보고 각자 다른 유형의 데이터를 접해보는 것입니다.

---

## 1. 역대 대회 출제 데이터셋은 이번 훈련에서 제외

실전 대회에서 그대로 나올 가능성이 있으니, 훈련용 선택지에서 미리 뺍니다.

| 회차 | 연도 | 출제 데이터셋 |
|---|---|---|
| 1회 | 2021 | 사출성형기 |
| 2회 | 2022 | 용해탱크 |
| 3회 | 2023 | 열처리 품질보증 |
| 4회 | 2024 | 주조 공정최적화 |
| 5회 | 2025 | 열처리 공정최적화 / 소성가공 품질보증 / 사출성형 공급망최적화 (3개 중 팀 선택) |

→ 제외 대상(7개): **사출성형기, 용해탱크, 열처리 품질보증, 주조 공정최적화, 열처리 공정최적화, 소성가공 품질보증, 사출성형 공급망최적화**

6회(2026) 실제 출제 데이터셋은 신청 마감(9/17) 이후 별도 공개 예정이므로, 공개되는 대로 다시 공유하겠습니다.

## 2. 카테고리별 후보 데이터셋

제외 7개와, 공정/품질/설비 어디에도 딱 맞지 않는 공급망·자원·생산계획 최적화류 8개(발주량 예측, 인력배치 등 경영·물류형 데이터)를 뺀 **35개**를 세 카테고리로 나눴습니다. (분류 기준: `2_도메인_조사자료` 4장의 "공정/품질/설비 데이터 차이")

### 공정 관점 (공정조건 자체를 다루는, 4개)

| 데이터셋 | 우선순위 | 이런 걸 배울 수 있음 |
|---|---|---|
| 공정운영 최적화 (표면처리) | A | 표면처리 라인의 첫 단계 데이터. 이후 전해탈지/도금욕/크로메이트와 구조가 비슷해서, 여기서 익히면 다른 표면처리 데이터도 빠르게 이해됨 |
| 생산공정 최적화 (사출성형·콘택트렌즈) | A | "불량 여부를 맞히기"가 아니라 "어떤 조건을 쓰면 좋을지 추천"하는 문제로 관점이 바뀌는 사례 |
| 용접 공정최적화 | B | 불량에 영향을 주는 변수 구간을 XGBoost/LightGBM으로 찾아 관리 구간을 제시하는 방식 |
| 의류 공정최적화 (염색) | C | 품질예측모델 + 유전알고리즘을 결합해 최적조건을 도출하는 2단계 구성 |

### 품질 관점 (완제품의 양/불·품질수치를 다루는, 16개)

| 데이터셋 | 우선순위 | 이런 걸 배울 수 있음 |
|---|---|---|
| 주조 품질보증 (다이캐스팅) | A | 컬럼 헤더 자체가 `공정조건→센서→불량유형`으로 그룹화된, "공정→품질" 흐름을 가장 잘 보여주는 데이터 |
| 머신비전 (열화상) | A | 이미지 1장 = 양/불 라벨 1개인 순수 "이미지 분류"의 대표 사례 |
| X-ray 검사장비 | A | 이미지 안에서 이물질 "위치"까지 찾는 "객체탐지" 문제의 대표 사례 |
| CNC 머신 | A | 가공조건(조건표) + 원본 시계열을 조인해서 분석해야 하는, 파일이 여러 개인 실전형 구조 |
| 용접기(스팟용접) | A | 라벨이 아예 없어서 "비지도 이상치탐지"로 접근해야 하는 사례 |
| 전자부품(음향기기) 품질보증 | A | 50개 중 유일한 오디오 데이터 |
| 정밀가공 품질보증 | B | 원본 시계열이 아니라 이미 통계 요약(평균/최댓값 등)된 형태 — 실전에서 자주 만나는 파생변수 활용형 |
| 화장품 품질보증 | B | 공정 센서(수만 행)와 품질검사표(수십 행)의 측정 빈도가 크게 다른 경우를 다루는 연습 |
| 배터리팩 품질보증 | B | 셀 176개 전압을 개별 컬럼으로 갖는, "완제품=부품 집합" 구조 |
| 기계부품 품질보증 (냉간단조) | B | 결측치가 실제로 많은 데이터 — 결측 처리 연습에 적합 |
| 의류 품질보증 (염색) | B | 색상이라는 특이한 품질 기준(색차)을 다루는 사례 |
| 프레스기 | B | 라벨 없이 군집화(GMM)로 불량 유형 자체를 나눠보는 접근 |
| 살균기 | B | Decision Tree로 품질 판정에 중요한 변수를 해석 가능한 형태로 뽑는 연습 |
| 품질이상탐지 (전해탈지/도금욕/크로메이트) | B | 센서 로그 + 별도 불량Lot목록을 결합해야 라벨이 생기는 실전형 구조 |
| 소성가공 품질보증(압출) | B | 대회 5회 출제작(제외 대상)과 자매 데이터 — 참고만, 실제 훈련은 다른 걸로 |
| 제조현장용 OCR / Scene-Text | B | 이미지 기반 "측정 자동화" 특수 사례 (숫자 인식) |

### 설비 관점 (설비 자체의 물리적 상태를 다루는, 15개)

| 데이터셋 | 우선순위 | 이런 걸 배울 수 있음 |
|---|---|---|
| 열처리 예지보전 | A | "로 내부가 860℃라 사람이 수시로 못 본다"는, 예지보전이 왜 필요한지 가장 명확하게 보여주는 사례 |
| 로봇용접 예지보전 | A | 진동+전류 두 신호를 결합한, 완성도 높은 예지보전 정석 사례 |
| Ford 엔진 진동 | A | 이미 정제된 공개 벤치마크. "파형=관측치 1개"라는 형태를 가장 쉽게 연습 가능 |
| 회전기계 고장유형 | A | 고장 데이터가 부족해 일부러 고장을 낸 실험장치(testbed)로 모은 데이터 — 불균형 문제의 원인을 체감 |
| 교반구동장치 | A | 라벨 없이 진동값만으로 설비 정상작동 여부를 판단하는 사례 |
| CNC 머신 | A | (품질 관점과 동시에 설비 관점도 가능 — 공구마모 축으로 보면 설비 데이터) |
| 건조구동장치 | B | 교반구동장치와 유사 구조, PCA 기반 접근 비교용 |
| 장비이상 조기탐지 | B | 센서 + 소리(오디오)를 동시에 쓰는 결합형 사례 |
| 정밀가공 자원최적화(레이저홀) | B | 이름은 "자원최적화"지만 실제로는 레이저 반사광 이상탐지 — 이름만 보고 판단하면 안 되는 사례 |
| 소성가공 예지보전 | B | 유압펌프 진동/전류로 고장을 조기 탐지 |
| 용접 예지보전 | B | 용접기 "노즐"이라는 부품 단위 예지보전 |
| 사출성형 예지보전 | B | 완제품 품질이 아니라 설비 자체 상태를 보는 사출성형 데이터 (사출성형기는 품질 관점 데이터셋도 따로 있어 비교 가능) |
| 배터리팩 예지보전 | B | 레이저 용접설비의 이상을 사전 예측하는 최신 산업(전기차 배터리) 사례 |
| 기계부품 품질보증 (냉간단조) | B | 전류·알람 신호 중심이라 설비 관점으로도 분석 가능 (품질 관점과 겹침) |
| 주조 설비 예지보전 | B | 다이캐스팅 설비의 "정상 vs 가생산(예열)" 상태를 구분하는 사례 — 주조 품질보증(품질 관점)과 짝지어 비교하면 좋음 |

## 3. 진행 방식 제안

1. **선택**: 각자 공정/품질/설비 중 하나를 고르고, 그 안에서 데이터셋 1개를 선택 (되도록 서로 겹치지 않게 조율, A급부터 우선 고려)
2. **분석**: `3_데이터분석_프로세스`의 단계를 따라 모의 분석 진행 (KAMP AI-PaaS 또는 KAMP-NOTE 활용 가능)
3. **발표**: 각자 짧게 발표 — 어떤 도메인 문제였는지, 어떤 문제정의를 세웠는지, 어떤 결과가 나왔는지, 확장 가능성은 무엇인지
4. **피드백**: 팀원들이 서로 `3_데이터분석_프로세스` 4장의 평가지표 관점(특히 문제정의 체계성 / 결과해석 우수성 / 확장성)으로 피드백
5. 이 과정을 통해 팀 전체가 공정/품질/설비 세 관점을 모두 한 번씩 경험하고, 실제 대회 데이터셋이 무엇이든 빠르게 적응할 수 있도록 합니다.
