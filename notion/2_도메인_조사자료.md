# 제조 도메인 조사 자료

KAMP 50개 데이터셋을 실제로 열어(zip 내부 컬럼, 공식 가이드북) 정리한 제조 도메인 배경지식입니다. **[사실]** = 데이터/공식 문서에서 직접 확인된 내용, **[추론]** = 일반적인 제조 지식으로 유추한 내용입니다.

---

## 1. 큰 그림: 제조 데이터가 만들어지는 6단계

업종은 달라도 데이터가 만들어지는 흐름은 항상 같습니다.

```
제조산업 → 제조공정 → 설비 → 공정에서 발생하는 현상 → 센서/검사 데이터 → 품질/설비 문제 → 데이터로 확인 가능한 문제
```

즉 "제조산업(예: 식품가공)" 안에 "제조공정(예: 용해공정)"이 있고, 그 공정을 "설비(예: 용해탱크)"가 수행하며, 그 과정에서 "현상(예: 온도 변화)"이 생기고, 이를 "센서 데이터(온도값)"로 기록하며, 그 결과가 "품질/설비 문제(불량, 고장)"로 나타나고, 우리는 그 데이터로 "확인 가능한 문제(불량 예측, 고장 예측 등)"를 풉니다.

> KAMP 데이터셋은 "원본 그대로"가 아니라 이미 한 번 정제된 "분석용 테이블"입니다. 실제 현장에서는 PLC·MES·센서 로거가 각각 따로 데이터를 쌓고, 이를 합치는 전처리가 별도로 필요합니다.

---

## 2. 공정군별 정리

50개는 크게 9개 공정군으로 묶입니다. 같은 공정군은 설비·변수·불량 개념이 거의 동일해서, 하나를 깊게 이해하면 나머지는 빠르게 이해됩니다.

### 절삭/정밀가공군 (CNC, 정밀가공 품질보증/자원최적화)
- CNC(Computer Numerical Control)는 절삭가공을 컴퓨터로 자동 제어하는 방식. 핵심 부품은 **spindle**(공구를 고속 회전시키는 축)과 X/Y/Z축 서보모터.
- **[사실]** CNC 데이터는 "지시값(Set)"과 "실제값(Actual)"을 같이 기록 — 기계가 지시대로 움직였는지, 그때 얼마나 힘(전류)이 들었는지를 함께 봄.
- **[사실]** `feedrate`(이송속도), `clamp_pressure`(고정압력)가 조건으로 기록되고, 결과는 `tool_condition`(공구마모)과 `passed_visual_inspection`(육안검사 통과)로 구분 — 설비 문제(공구마모)와 품질 문제(불량)가 별도 라벨로 존재.
- 핵심 용어: **spindle**, **feed rate**, **공구 마모**

### 성형(사출·프레스·소성가공)군
- 원재료에 열·압력·속도를 가해 금형 안에서 형태를 만드는 공정. 사출성형(수지를 금형에 주입)/프레스(판재를 눌러 찍음)/소성가공(압출·단조 등 포함 상위개념).
- **[사실]** 사출성형 데이터는 `Injection_Time, Filling_Time, Cycle_Time, Max_Screw_RPM` 등 시간·위치·속도로 세분화되어 기록되고, `PassOrFail` + `Reason`(불량 사유 텍스트)까지 라벨링됨.
- 핵심 용어: **금형(mold)**, **cycle time**(제품 1개를 만드는 데 걸리는 시간, 이 공정군의 핵심 KPI), **클램핑**

### 용접군
- 두 금속을 열·압력·전류로 붙이는 접합 공정. 스팟용접(점 단위로 짧게 큰 전류를 흘림)이 대표적.
- **[사실]** `용접 가압력, 전류, 전압, 통전시간`이 핵심 변수. 라벨 없이 "비지도 이상치 탐지"로 접근하는 경우가 많음(정상 범위를 벗어난 것 = 불량 후보).
- **[추론]** 전류가 부족하면 미용착, 과하면 번아웃/스패터 가능성.
- 핵심 용어: **스팟용접**, **통전시간**, **미용착**

### 주조군 (다이캐스팅)
- 금속을 녹여 금형에 고압으로 빠르게 주입해 굳히는 다이캐스팅.
- **[사실]** 컬럼 헤더가 `Process`(공정조건: Velocity, Pressure 등) → `Sensor` → `Defects`(불량유형)로 그룹화되어 있어 "공정조건→현상→불량"의 흐름을 그대로 보여줌.
- **[사실]** "가생산(warm-up run)": 설비가 정상 온도 도달 전 예열 중 나오는, 처음부터 폐기 전제인 제품. **불량과는 다른 개념** — 불량은 몰라서 생기는 문제, 가생산은 알고도 감수하는 예열 비용.
- 핵심 용어: **다이캐스팅**, **shot(사출 1타 = 제품 1개)**, **가생산**

### 열처리군
- 금속을 고온 가열 후 급랭(담금질)시켜 강도·경도를 바꾸는 공정.
- **[사실]** 소입로·건조로·염욕조(salt bath)로 구성, 로가 여러 구간(Zone)으로 나뉘어 각기 온도 제어됨.
- **[사실]** 열처리는 2시간 이상 걸리는 연속공정이라 불량이 나와도 즉시 알기 어렵고 설비를 세우기도 어려움 — 그래서 "사전 예측(예지보전)"이 특히 중요한 공정으로 소개됨.
- 핵심 용어: **담금질**, **소입로**, **Carbon Potential(CP)**, **염욕**, **Zone**

### 표면처리군 (전해탈지 → 도금 → 크로메이트)
- 금속 표면에 방청·미관·전기적 성질을 부여하는 화학처리 라인.
- **[사실]** 여러 데이터셋이 같은 사업장·비슷한 시기의 센서 로그(`kemp-abh-sensor-*.csv`)를 공정 단계별로 나눠 제공. 각 단계마다 측정 변수가 다름 — 전해탈지(pH,Temp,Current) / 도금(+Voltage) / 크로메이트(pH,Temp,Voltage).
- **[사실]** 불량 Lot 목록(`Error Lot list.csv`)이 센서 로그와 별도 파일로 존재 — 날짜/Lot 기준 결합이 필요.
- 핵심 용어: **전해탈지**, **도금(전기도금)**, **크로메이트**, **PLC**, **Lot**

### 식품·화학 연속공정군 (용해 → 살균 → 건조)
- **[사실]** 분말·액상 원재료를 용해(녹이고 섞기) → 살균(가열 미생물 제거) → 건조(재분말화) 순서로 처리.
- **[사실]** 같은 용해탱크 설비라도 품질 라벨이 있는 데이터(`INSP`)와, 라벨 없이 진동값만 있는 설비 데이터가 별도로 존재 — "품질 데이터"와 "설비 데이터"가 같은 라인에서도 다름을 보여주는 사례.
- 핵심 용어: **SOP(표준운영절차)**, **교반**, **Lot**

### 전자부품·배터리 조립/검사군
- 배터리 셀→모듈→팩 조립, 레이저 용접, 충·방전 시험.
- **[사실]** 배터리팩 시험 데이터는 모듈(M01~M16)별 셀 전압을 176개 컬럼으로 개별 기록 — 완제품 하나가 다수 하위부품의 집합이라는 걸 컬럼 수로 확인 가능.
- **[사실]** OK/NG가 아예 폴더로 분리 제공되는 경우가 많아 지도학습 라벨이 깨끗함.
- 핵심 용어: **셀/모듈/팩**, **충방전**, **AAS**(Industry 4.0 설비 메타데이터 표준, `.aasx` 파일)

### 이미지·오디오 검사군
- 이미지 전체 1장에 라벨 1개("분류") vs 이미지 안 특정 위치를 찾는 라벨("객체탐지")로 문제 성격이 갈림.
- **[사실]** 안전관리 데이터는 CCTV 프레임에 사람 위치를 bounding box로 표시(객체탐지). Scene-Text는 저울 LED 숫자 하나하나를 문자 단위로 검출+인식(더 세밀한 탐지). 머신비전은 이미지 1장=양/불 라벨 1개(순수 분류).
- 오디오(음향기기 품질검사)는 소리를 파형(시계열)으로 다룸 — 50개 중 유일한 오디오 사례.
- 핵심 용어: **분류 vs 객체탐지**, **bounding box**, **YOLO**

## 3. 센서 변수 공통 정리

| 변수 | 무엇을 재는가 | 왜 중요한가 |
|---|---|---|
| 온도(Temp) | 설비/재료의 열 상태 | 열처리(강도 결정), 표면처리(반응속도), 사출성형(수지 유동성) 등 거의 모든 공정에서 등장 |
| 압력(Pressure) | 유압/공압/사출압 | 부족하면 성형 불량, 과하면 설비 부담 가능성 |
| 속도(Velocity) | 이송·회전·주입 속도 | 너무 빠르면 품질 불안정, 느리면 생산성 저하 |
| 전류(Current) | 모터/전기설비 전기량 | 용접 접합 에너지, 전기도금 반응속도, 모터 부하 이상 신호 |
| 전압(Voltage) | 전기설비 전위차 | 전류와 함께 관찰, 배터리는 셀 상태 자체를 나타내는 핵심 지표 |
| 진동(Vibration) | 설비의 미세한 흔들림 | 회전체·모터·베어링의 물리적 상태를 가장 직접적으로 보여줌 |
| pH | 산성/알칼리성 | 표면처리 화학조의 농도·반응성 지표 |
| cycle time | 제품 1개(1shot)당 소요시간 | 생산성 지표이자 평소보다 길어지면 설비 이상 신호 가능성 |

**패턴**: 대부분의 데이터가 "목표값(Set/지시)"과 "실제값(Actual/진행)"을 쌍으로 기록합니다. 이 둘의 **편차** 자체가 품질에 영향을 주는 파생 변수일 수 있습니다.

## 4. 품질과 불량

- **Lot**: 같은 조건으로 함께 처리된 제품 묶음(표면처리·염색 등 배치 공정에서 흔함)
- **Shot**: 사출성형·다이캐스팅처럼 한 번 누를 때마다 제품 하나가 나오는 공정의 동작 단위
- **불균형 데이터**: 제조 현장은 정상 제품이 압도적으로 많고 불량은 드묾(회전기계 데이터셋 공식 설명: "정상 유형이 90% 이상"). 그래서 일부러 고장을 낸 실험장치(testbed)로 데이터를 모으거나, 정상 데이터만으로 학습하는 비지도 이상치탐지 방식을 쓰는 경우가 많음.
- **공정 데이터 / 품질 데이터 / 설비 데이터**는 같은 라인에서도 성격이 다를 수 있음:
  - 품질 데이터: 최종 제품 양/불량 라벨 (예: `PassOrFail`)
  - 설비 데이터: 설비 자체 물리 상태, 제품 라벨 없을 수 있음 (예: 진동값만)
  - 공정(운영) 데이터: 위 둘의 원인이 되는 조건값 자체

---

## 5. 설비 이상과 예지보전

- **이상탐지**: 지금 이 순간의 데이터가 평소와 다른가?
- **예지보전(PdM)**: 지금 추세로 가면 앞으로 고장/비정상이 될 것인가? (이상탐지보다 한 단계 더 나아간 "사전 조치" 개념)
- **오토인코더(Autoencoder)**: 정상 데이터만으로 학습해 입력을 복원하고, 복원이 잘 안 되는(재구성 오차가 큰) 경우를 이상으로 판단 — 불량 샘플을 충분히 모으기 어려운 제조 현장에서 자주 쓰이는 이유.
- **Decision Tree/XGBoost 계열**: 정상/불량을 가르는 기준을 사람이 해석하기 쉬운 형태로 찾아낼 때 자주 사용.

## 6. 제조데이터의 대표적인 형태

1. **연속 시계열 센서 로그** — 한 행 = 한 시점 (가장 많음)
2. **배치(Lot/Shot) 단위 정형 데이터** — 한 행 = 제품/로트 하나, 시계열을 통계 요약해서 만드는 경우 많음
3. **파형(waveform) 시계열** — 컬럼 자체가 시간축, 한 행 = 사건 하나의 전체 파형
4. **이미지** — 분류용(1장=라벨1개) / 탐지용(1장=여러 위치+라벨)
5. **오디오(wav)**
6. **텍스트/공급망 테이블** — 발주량, 생산계획 등 제조 현상이 아닌 비즈니스 활동 기록

## 7. 분석 문제 유형 10가지

| 유형 | 정의 | 전형적 입출력 |
|---|---|---|
| 품질 예측 | 공정조건→품질 수치(연속값)를 회귀로 추정 | 공정변수 → 연속값 |
| 품질 분류 | 공정조건/제품 데이터→양품/불량 분류 | 공정변수 → 범주(OK/NG) |
| 불량 탐지 | 완성품 자체(이미지·검사값)에서 불량 유무/위치 탐지 | 이미지/검사값 → 불량 여부·위치 |
| 설비 이상탐지 | 현재 설비 상태가 정상 범위를 벗어났는지 판단 | 센서 시계열 → 정상/이상(현재) |
| 예지보전 | 앞으로 설비 문제가 생길지 미리 예측 | 센서 추세 → 향후 이상 가능성 |
| 공정 분석 | 변수 간 상관관계·영향도 탐색 | 공정변수 전체 → 변수 중요도 |
| 공정 최적화 | 불량을 줄이는 최적 조건 탐색 | 공정변수+결과 → 추천 조건값 |
| 이미지 검사 | 컴퓨터비전으로 육안검사 대체 | 이미지 → 분류/객체탐지 결과 |
| 시계열 분석 | 시간 흐름 자체가 중요한 패턴/예측 문제 | 시계열 → 미래값/패턴 |
| 기타 | 스케줄링, 자원배분 등 | 제약조건 → 최적 배치 |

## 8. 제조 용어 미니 사전

| 용어 | 뜻 |
|---|---|
| Lot / Shot | 같은 조건 처리 묶음 / 성형 1회 동작(=제품 1개) |
| cycle time | 제품 1개(1 shot)를 만드는 데 걸리는 총 시간 |
| SOP | 표준운영절차 |
| PLC | 설비 센서값을 읽고 제어신호를 내보내는 산업용 제어기 |
| MES | 생산관리시스템 (Lot 단위 생산·불량 이력 관리) |
| spindle / feed rate | CNC의 공구 회전축 / 이송 속도 |
| 담금질 / 소입로 / 염욕 | 고온가열 후 급랭 처리 / 그 가열로 / 소금물 열처리 방식 |
| 전해탈지 / 도금 / 크로메이트 | 표면처리 순서: 기름때 제거 → 금속막 입힘 → 부식방지 피막 |
| 다이캐스팅 / shot / 가생산 | 고압 금형주조 / 사출 1타 / 설비 예열 중의 의도된 폐기 생산 |
| 진동(vibration) | 회전기계 상태 진단의 핵심 신호 |
| 오토인코더 | 정상 데이터로만 학습해 복원 오차로 이상을 판단하는 비지도 모델 |
| AAS | 설비를 표준 형식으로 기술하는 Industry 4.0 메타데이터 규격 |
| bounding box | 이미지에서 물체 위치를 표시하는 사각형 좌표 |
